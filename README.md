## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

### Prerequisites
Make sure install Git to PC.
Make sure you have Node.js installed on your machine. and also install git.
For first time or beginner or doesn't even know what PC is please search Node.js and npm. 
Might help in the future.

### Installation

1. **Clone the repository** (if applicable):
   
   [git clone (https://github.com/EmirErfan/ladang-pro.git)](https://github.com/EmirErfan/ladang-pro.git)

2. **Navigate to the project directory**
    cd ladang-pro

3. **Install NPM packages**
    npm install

4. **Run the development server**
    npm run dev

5. **Open your browser** and navigate to `http://localhost:8080` (or the port specified in your terminal).

## 📂 Project Structure

A quick look at the core files that drive the application:

*   **`src/routes/__root.tsx`**: The main layout wrapper that handles the global sidebar and full-screen page logic.
*   **`src/routes/index.tsx`**: The beautiful landing page featuring the embedded quick calculator and slide-down results.
*   **`src/routes/dashboard.tsx`**: The main user hub containing the visual emission breakdown and historical trends.
*   **`src/lib/store.ts`**: The "Fake Database" handling simulated authentication, session memory, and user-isolated history.
*   **`src/lib/carbon.ts`**: The math engine. Contains emission factors, calculation logic, and the smart recommendation database.
